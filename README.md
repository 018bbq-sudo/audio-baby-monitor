# Аудиорадионяня для Android

MVP передаёт только живой звук. Видео и запись отсутствуют. Один и тот же APK работает в двух режимах: **Детская** и **Родитель**.

## Что уже реализовано

- работа при выключенном экране через foreground service;
- моно 16 кГц и лёгкий IMA ADPCM (около 65 кбит/с до сетевых накладных расходов);
- экономия в тишине: полный кадр отправляется примерно раз в секунду;
- автоматическое переподключение;
- сквозное AES-256-GCM шифрование: сервер пересылает непрозрачные пакеты и не имеет ключа;
- сервер не пишет звук на диск и хранит комнаты только в памяти;
- постоянное уведомление и системный индикатор микрофона на телефоне в детской.

## Быстрая проверка в одной Wi-Fi сети

1. На компьютере с Node.js 20+ выполните:

   ```powershell
   cd server
   node server.mjs
   ```

2. Узнайте локальный IP компьютера, например `192.168.1.10`.
3. Установите APK на оба Android-телефона.
4. На обоих введите `ws://192.168.1.10:8080/audio` и одинаковый код комнаты.
5. На одном нажмите **Этот телефон — в детской**, на другом — **Этот телефон — у родителя**.

Windows Firewall может запросить разрешение для Node.js в частной сети.

## Работа через интернет

Разместите папку `server` на любом Docker-хостинге, который выдаёт публичный HTTPS-адрес и поддерживает WebSocket. В приложении укажите этот адрес с протоколом `wss://`, например `wss://ваш-домен.example/audio`.

### Простой бесплатный тест на Render

1. Создайте новый репозиторий GitHub и загрузите в его корень содержимое этого проекта. Файл `render.yaml` должен оказаться в корне репозитория.
2. В Render выберите **New → Blueprint**, подключите репозиторий и подтвердите создание сервиса `audio-baby-relay`.
3. Дождитесь состояния **Live** и скопируйте выданный адрес вида `https://audio-baby-relay-xxxx.onrender.com`.
4. На обоих телефонах введите адрес `wss://audio-baby-relay-xxxx.onrender.com/audio` и одинаковый код комнаты.

Бесплатный сервис может около минуты просыпаться после простоя. Он предназначен для испытаний; для постоянной ночной работы потребуется следить за лимитом исходящего трафика или перейти на платный сервер.

```powershell
docker build -t audio-baby-relay server
docker run --rm -p 8080:8080 audio-baby-relay
```

Не публикуйте сервер наружу как обычный `ws://`: для интернета нужен `wss://`. Сам звук дополнительно зашифрован кодом комнаты, однако TLS защищает служебные данные и соединение от подмены.

## Расход ресурсов

Кодек специально выбран с очень небольшой нагрузкой на процессор. Типичный трафик во время звука — порядка 35–45 МБ/ч; в тихой комнате с включённой экономией значительно меньше. Фактический расход батареи зависит от телефона и качества сети.

## Сборка

Откройте корень проекта в Android Studio и выберите **Build → Build APK(s)**. Требуются Android SDK 37 и JDK 17+.

Это тестовая версия. Перед использованием ночью проверьте её несколько часов на своих телефонах, отключите для приложения оптимизацию батареи при необходимости и оставьте телефон в детской на безопасной зарядке.
